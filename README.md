# Budget Frog 🐸

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A friendly budget tracking web application that helps you manage your personal finances effectively.

![Budget Frog Screenshot](./screenshots/demo.png) <!-- Add your screenshot path -->

## Features

- **Expense/Income Tracking**: Add and categorize financial transactions
- **Visual Reports**: Interactive charts for spending patterns
- **Budget Goals**: Set monthly spending limits for different categories
- **Data Persistence**: Local storage for maintaining transaction history
- **Responsive Design**: Works on both desktop and mobile devices
- **Transaction Management**: Edit or delete existing entries
- **Financial Summary**: Real-time balance, income, and expense calculations

## Technologies Used

- **HTML5**: Semantic structure and content
- **CSS3**: Styling and animations
- **JavaScript**: Core functionality and interactions
- **Chart.js**: Data visualization
- **Local Storage**: Data persistence
